# KOPORA06 — VS Code 편집용 웹사이트

2026-10-13에 배포된 KOPORAO6의 샘플 48개와 연구소장 인사말을 포함한 소스입니다.
HTML·CSS·JavaScript로 구성되어 있으며 npm 설치나 빌드가 필요하지 않습니다.

## 1. 열기

1. ZIP 파일을 다운로드하여 먼저 압축을 모두 풉니다.
2. Visual Studio Code를 실행합니다.
3. 파일 → 폴더 열기에서 압축을 푼 `KOPORA06` 폴더를 선택합니다.
   또는 `KOPORA06.code-workspace` 파일을 VS Code에서 엽니다.
4. 폴더 안의 `index.html`을 브라우저로 열면 화면을 볼 수 있습니다.
5. 파일을 수정하고 Ctrl+S로 저장한 다음 브라우저를 새로고침합니다.

편집 시 긴 코드는 VS Code에서 Shift+Alt+F(문서 서식 지정)를 눌러 정리할 수 있습니다.

## 2. 어떤 파일을 수정하나요?

| 파일 | 수정할 내용 |
|---|---|
| index.html | 브라우저 제목, 상단 로고, 공통 헤더·푸터, 안내창 |
| style.css | 남색·옐로우 색상, 글꼴 크기, 간격, 모바일 화면 |
| app.js | 메뉴, 메인 구성, 목록·상세 화면, 인사말, 공사 중 안내 |
| samples.js | 자료·사례·칼럼·작품 등 샘플 48개 |
| assets/ | 이미지 3개, 영상 6개, 음악 3개 |

색상은 style.css 상단의 `--navy`, `--yellow`를 수정합니다.
인사말은 app.js에서 `사람의 정체성을 존중하고`를 검색하면 찾을 수 있습니다.
메뉴 이름은 app.js 맨 위의 `menus`에서 수정합니다.

app.js에는 첫 화면용 기본 함수(baseHome/baseAbout)와 확장 함수(home/about/page/read)가 함께 있습니다.
샘플 목록과 상세 페이지 수정은 파일 하단의 마지막 page/read 함수를 기준으로 하세요.

## 3. 글 수정 및 추가

samples.js에서 원하는 제목을 Ctrl+F로 검색합니다.
- title: 제목
- summary: 목록에 표시되는 요약
- text: 상세 본문. 배열의 각 문자열이 한 문단입니다.
- section / sub: 대분류와 세부 분류
- label: 실제 자료·가상 사례·편집 샘플 등의 표시
- source / sourceName: 원문 링크와 출처 이름
- country: 국가 필터

새 글을 추가하려면 기존의 비슷한 항목을 복사하고, id를 중복되지 않는 값으로 바꿉니다.
항목 사이의 쉼표와 문자열의 따옴표를 유지하세요.

| section | sub |
|---|---|
| portrait | 권리관계, 사례 |
| ai | 권리관계, 사례 |
| archive | 초상권 / 법령, 초상권 / 판례, 초상권 / 논문, AI생성콘텐츠 / 법령, AI생성콘텐츠 / 판례, AI생성콘텐츠 / 논문 |
| gallery | 시네마, 동영상, 음악, 이미지 |
| column | 연구소 칼럼, 전문가 칼럼 |

분류 이름을 바꾸면 menus와 samples.js의 해당 값도 함께 맞춰야 합니다.

## 4. 작품 교체

assets 폴더에 새 파일을 넣고 samples.js의 다음 항목을 수정합니다.
- media: 파일 경로(예: assets/my-movie.mp4)
- mediaType: video / audio / image
- poster: 영상·작품 카드의 대표 이미지 경로
- duration: 화면에 표시할 길이 또는 작품 수

파일명은 영문 소문자·숫자·하이픈을 사용하면 관리하기 편합니다.
로컬에서 잘 보이더라도 호스팅 환경에서는 대소문자가 다르면 파일이 표시되지 않을 수 있습니다.

## 5. 선택 사항: 로컬 서버

Python이 설치되어 있다면 VS Code 터미널에서 아래 명령으로 열 수도 있습니다.

```sh
py -m http.server 5500 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:5500 을 엽니다. 종료는 터미널에서 Ctrl+C입니다.
Mac/Linux는 py 대신 python3를 사용하세요. Python이 없어도 index.html 직접 열기로 확인 가능합니다.

## 6. 현재 구현 범위

- 콘텐츠 목록·검색·국가 필터·상세 화면
- 영상·음악 재생 및 이미지 감상
- 연구소장 인사말 초안
- 회원가입·방문자 로그인·관리자 기능은 공사 중 안내
- 실제 인증·서버 저장·파일 업로드 기능은 아직 연결되어 있지 않음

로컬에서 수정·저장해도 기존 온라인 사이트에는 자동 반영되지 않습니다.
수정본을 온라인에 반영하려면 별도 배포가 필요합니다.
ChatGPT Sites의 비공개 접근 제한은 이 소스 파일에 포함되지 않습니다.
다른 호스팅 서비스에 올릴 때 공개 범위는 해당 서비스에서 설정해야 합니다.

## 7. 포함된 콘텐츠와 외부 연결

48개 샘플은 실제 자료 링크, 가상 학습 사례, 편집용 칼럼, 감상용 작품으로 구분되어 있습니다.
전문가 칼럼은 실제 전문가의 기고문이 아닙니다. 인사말은 검토·수정할 수 있는 초안입니다.
영상은 AI 생성 이미지 기반 모션 샘플이며 음악은 코드로 합성한 샘플입니다.

이미지·영상·음악은 ZIP에 모두 포함되어 있습니다.
Pretendard 글꼴은 인터넷 CDN에서 불러오므로 오프라인에서는 대체 글꼴로 표시될 수 있습니다.
법령·판례·논문 원문 링크는 인터넷 연결이 필요합니다.
